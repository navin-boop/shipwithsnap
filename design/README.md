# design/

The product and system design for Ship with Snap, one artboard per file. `canvas.json` is the index: which page each artboard sits on, its display title and frame size.

- Open any `*.dc.html` in a browser to see the screen; the clickable ones (Ship, Batch, Shipments, Billing, Reports, Settings, phone Ship flow, sign-in) work standalone.
- The live, editable canvas is the "Ship with Snap" artifact in Claude; edits saved there should be pulled back into this folder, and changes here re-saved to the canvas — ask Claude to do either.
- File names are stable identities; a few are historical (`Wallet` → Billing screen, `Ledger` → Billing & payments sheet, `CarrierAdapter` → EasyPost integration). `canvas.json` carries the current titles.
- `SystemMap` and `DirectionA/B/C` are archived early sketches.

See the root `CLAUDE.md` for the token table and the screen → artboard map.
